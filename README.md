## About Me

Full-stack developer from Vienna. I work in **Platform & IT at TechTalk**, study Computer Science (CSDC) at **Hochschule Campus Wien** and co-founded **[yPanda](https://ypanda.at)**. My background is in biomedical informatics (HTL Spengergasse), which is where projects like the HL7 FHIR backend and the bioinformatics toolbox come from.

I build across the stack — Spring Boot and .NET backends, Django services, React and Angular frontends — and increasingly the infrastructure underneath.

- 🏗️ **Now:** Azure infrastructure with Bicep, Microsoft 365 & Graph automation with PowerShell
- 🤖 **Into:** local AI models and self-hosted, privacy-first tooling
- 🌐 **Maintaining:** the website of a Vienna high school (WordPress, custom plugin + child theme)
- 🗣️ **Languages:** German, English, Arabic
