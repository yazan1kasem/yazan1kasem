## About Me

Backend developer and infrastructure engineer from Vienna. At **TechTalk** I work on Azure infrastructure, Microsoft 365 / SharePoint automation and internal tooling. Alongside that I study Computer Science (CSDC) at **Hochschule Campus Wien** and co-founded **[yPanda](https://ypanda.at)**.

I like systems that are boring to operate: automated, documented, and running on infrastructure I control.

- 🏗️ **Now:** Azure landing zones with Bicep, SQL Managed Instance networking, Microsoft Graph automation
- 🔐 **Into:** privacy-first and local-first tooling — offline embeddings, local models, self-hosting
- 🌐 **Maintaining:** the website of a Vienna high school (WordPress, custom plugin + child theme)
- 🎮 **Off-hours:** gaming and the occasional Pygame side project
